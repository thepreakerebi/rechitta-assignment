# Gradient Orb

The orb shader in `app/utils/orb/shaders.ts` is derived from **Gradient Orb** by
Kaiyu Hsu (UI Capsule), published at https://uicapsule.com/ui/gradient-orb and
listed at https://21st.dev/@uicapsule/components/gradient-orb.

The original is a React component built on `three` and `@react-three/fiber`.
This project uses the GLSL only, on a hand-rolled WebGL2 renderer, with the
palette retuned and the animation driven by microphone input.
